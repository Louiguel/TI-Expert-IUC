
# Plan de tests

## 1. Tests fonctionnels

- Vérifier l'affichage de toutes les sections.
- Vérifier les liens de navigation.
- Vérifier le lien externe vers le site de l'IUC.
- Vérifier l'ouverture et la fermeture du menu mobile.
- Vérifier l'affichage de l'année courante.

## 2. Tests responsive

- Tester un écran de bureau.
- Tester une tablette.
- Tester un smartphone.
- Vérifier l'absence de défilement horizontal involontaire.

## 3. Tests techniques

- Vérifier le chargement de la feuille CSS.
- Vérifier le chargement du JavaScript.
- Vérifier la console du navigateur.
- Vérifier les chemins relatifs des fichiers.

## 4. Tests d'accessibilité de base

- Vérifier la structure des titres.
- Vérifier les libellés du menu.
- Vérifier le focus clavier.
- Vérifier le contraste des couleurs.

## 5. Résultats
