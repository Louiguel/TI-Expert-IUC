
# Architecture technique

## 1. Vue générale

Le site est une application web statique composée de trois technologies
principales : HTML, CSS et JavaScript.

## 2. Structure

- index.html : structure et contenu des sections.
- css/style.css : couleurs, typographie, disposition et responsive design.
- js/main.js : menu mobile et affichage dynamique de l'année.
- images/ : ressources graphiques.
- docs/ : documentation du projet.

## 3. Fonctionnement

1. Le navigateur charge index.html.
2. Le navigateur applique css/style.css.
3. Le fichier js/main.js ajoute les interactions.
4. Les liens internes permettent de naviguer entre les sections.
5. Le lien externe ouvre le site officiel de l'IUC.

## 4. Architecture des données

Aucune base de données n'est utilisée dans cette version.

## 5. Évolutions possibles

- Ajouter des pages dédiées aux formations.
- Ajouter des images officielles.
- Ajouter un formulaire relié à un service autorisé.
- Ajouter une procédure de déploiement continu.
