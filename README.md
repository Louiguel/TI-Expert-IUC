
# TI Expert IUC

Site web de présentation du département des Technologies de l'Information
de l'Institut Universitaire de la Côte à Douala.

## Objectifs

- Présenter le département.
- Décrire les cycles et spécialités de formation.
- Présenter les domaines d'expertise.
- Mettre en valeur les atouts pédagogiques et techniques.
- Appliquer les bonnes pratiques de développement collaboratif avec GitHub.

## Technologies

- HTML5
- CSS3
- JavaScript
- Git et GitHub

## Installation locale

1. Cloner le dépôt.
2. Ouvrir le dossier dans Visual Studio Code.
3. Ouvrir index.html dans un navigateur.

Aucune installation de dépendance n'est requise pour cette version.

## Arborescence

- index.html : page principale.
- css/style.css : styles.
- js/main.js : interactions.
- images/ : ressources graphiques.
- docs/ : documentation technique.
